1. About this Project
This project is desktop app using Python code and TKinter.
TKinter can make GUI app, in other words, if you use TKinter it will be not only program that typing the text to a brack screen. It can allow to have button and input box and windows.
Purpose of this code is managing the taunament and it shuld allow to add players, choose type(individual, team),edit and delate player.Also  allow to make a new event, allow to connect players to event, allow to input position, allow to set a connection of position and point, allow to show result of ranking and shold calculate automatically, also allow to save the data with JSON.
